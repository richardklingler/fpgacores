# 74x08 — quad 2-input AND gate

Four independent AND gates, `Yn = An & Bn`, as in the 74LS08, 74HC08 and
74HCT08. Used by GateLab's KiCad import: the package pin table in `core.json` maps KiCad's pin
numbers to the ports. Zero-delay model — for simulation and as an FPGA starting point; synthesis maps it to LUTs.
